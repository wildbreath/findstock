# 复盘表按日收录

在复盘表顶部选择「收录日期」，点击「收录这一天」。显示日期区间只控制表格视图，收录日期独立选择。一次只填所选日期，不补写其他日期的行情。按时间顺序收录，已收录的日期可以重复更新。

收录读取本地已完整下载的收盘天梯和悟道题材，不发起收费接口调用。缺少天梯、悟道题材或计算分行所需的交易日历时，提示去数据页面补充，本次不写入复盘表。日期选项来自本地收盘天梯；有天梯仍可能需要补下载题材。

只新增沪深主板非ST、连板数至少2的股票。每行在首次行情日前两个交易日填写悟道主题材、股票名称。行情格填写当日收盘相对昨收的涨跌幅，连板时在格内同时标出高度，例如「3板 +9.97%」。优先使用当日日线涨跌幅，日线缺失时可用收盘天梯的涨跌幅；不根据入表价计算累计涨幅。后续断板仍更新同一行，普通上涨浅红、普通下跌浅绿，涨停深红、跌停深绿，平盘默认底色。涨停按当日收盘天梯确认；跌停按本地主板昨收九折、四舍五入到分后的价格判断，缺少价格时仅在跌幅达到10%时使用深绿，本地前复权价格可能影响历史跌停识别。已有日期重新收录后应用新格式，人工追加描述继续保留。缺少个股有效行情则保留原格，并列出缺失代码。

新增股按题材分堆。已有题材接在该堆尾部，新题材按本次新增数量降序排列，数量相同按名称排序。同日同题材按连板高度降序、首次封板时间升序、股票代码升序排列。历史记录不因后续连板高度变化而重排。悟道提供的主题材为空时显示「未分类」并提示，不用行业名称猜测。

不同题材组之间显示一行空白，已有空行不重复添加；分隔空行不占股票记录，方向键及框选直接跨过。题材名称格与左侧固定题材标签使用一致配色，不同题材使用不同颜色。普通行情仍按红涨绿跌显示，龙头紫色优先。

底部常驻左右按钮和日期滑块，可直接跳到最早或最新日期。「题材排序」支持拖动手柄、上移下移、置顶置底，或填写目标名次后点击「移动」或按 Enter。可以查找题材，名次始终按全部题材计算。同题材的全部行一起移动，保留行内顺序、隐藏日期、人工格式和跟踪状态；自动保存且可在窗口底部撤销、重做，之后新增股票仍加入已有题材位置。窗口内仅列表滚动，标题、关闭按钮和底部操作始终可见；可点关闭/完成、按 Esc 或点击窗口外关闭，已调整顺序继续保存。

「整体视图」收起侧边栏和编辑工具，压缩行高并尽量将全部日期铺满屏宽；使用「跳转题材」快速定位，返回编辑视图继续修改。

选中股票行后，可点「编辑题材」或使用右键同名操作，选择已有名称或输入新题材；支持同时修改所选多行。仅修正所选记录，不批量回改同代码的其他历史记录。相同题材名称会自动聚拢，保留题材排序、组内顺序、隐藏日期、人工描述、格式和停止状态；不同含义或近义名称不自动猜测合并。人工分类保存在复盘记录内，后续新一轮收录沿用该代码最新一轮记录中的人工分类；原始下载题材不改动。编辑题材、题材单元格改名和粘贴题材使用一致规则。

手工录入使用「加入个股」：默认从自选股选择，可按自选分类和名称/代码筛选；也可切换到连板天梯，选择天梯交易日并查看板数与题材，或搜索全部股票。可以跨来源、跨日期勾选多只，待加入清单会保留，也可勾选当前列表。统一选择题材和「加入日期（行情起点）」后，一次加入复盘表并自动归组；同一代码在其他题材里的记录会保留，仅跳过同代码、同题材、同加入日期的重复记录。

加入时按现有行情规则填写加入日期至本地最新完整收盘日的涨跌幅、连板高度和颜色，题材与名称放在加入日期前两个交易日，所需日期列自动扩展。只读取本地行情，不重新下载；缺失或停牌无有效行情的格子留空并提示，不填假数值。加入后按独立记录继续跟踪，后续「收录这一天」会更新各题材中的手动行，保留人工备注和标记。手动选股不限制为主板二板股，支持自选中的创业板、科创板等股票；自动新增股票仍遵循原筛选范围。增加其他题材请使用「加入个股」；「编辑题材」只修改所选记录归属。

「复制整行」可从工具栏或右键菜单使用，支持勾选多行。副本保留股票关联、全部日期（含隐藏列）、备注、格式、龙头和停止状态，使用新行编号独立保存；可单独修改副本题材或备注。复制的自动跟踪行会作为独立手动记录继续更新，不与原行争用行情。添加、补齐和复制均可整批撤销；Ctrl＋C 仍用于复制选区。

左侧复选框支持不相邻行多选，表头可全选；Shift＋点击行号连续选行，「选择同题材」可选中该题材全部记录。「取消多选」或点击普通单元格返回单元格编辑。勾选后可统一修改题材、设为/取消龙头、停止/恢复跟踪、整行移动、删除和设置可见日期格式；停止或恢复仍按股票代码作用于该股全部历史记录。复制只包含勾选行，粘贴前需要先点击一个单元格确定连续写入位置。勾选状态不保存，实际批量修改自动保存且可整批撤销。

「新增行」可以一次填写数量，选择选中行上方、下方、题材末尾或表尾，并默认沿用当前题材。已有题材保持聚拢，位置用于该题材内定位，新题材默认追加到表尾；也可用「上方插入」「下方插入」快速新增一行。新行在当前日期预设名称格并定位录入，多行连续按Enter可继续下一行。整批新增一次撤销；数量、日期和1000行上限会在修改前校验。

删除行后，下方记录整行上移，同题材聚拢，清理多余的空白记录；含隐藏日期内容、人工格式、股票关联或跟踪信息的行会保留。题材之间只显示一行分隔，不补尾部空行。删除及自动整理可一次撤销完整恢复。

工作区缩放同时作用于操作栏、编辑框、表格、左侧股票栏、日期表头和底部日期操作条。可选50%至200%，每10%一档，并保留75%和125%；可一键恢复100%。比例保存在当前浏览器，刷新或重新打开后恢复；清理浏览器数据或更换浏览器不会共享。整体视图临时使用适配布局，返回编辑视图恢复所选比例。

点击左侧股票名称打开共用K线弹窗，点击行号选择整行。自动收录行按股票代码查看；未关联的手填行首次搜索并明确选择股票，关联代码独立保存，不会仅因看图开启自动跟踪。修改手动加入行或副本的股票名称、将另一格设为名称格时，会解除旧股票关联和跟踪，保留历史行情与备注，避免继续填写原股票的数据；仅修改题材不会解除关联。全屏和整体视图均支持看图，关闭后保留表格位置与选中状态；缺少本地日线时提示先下载。

分行只计算上轮最后一次涨停到本轮首板之前的未涨停交易日；达到10天时，在本轮达到2板后另起一行。中间出现首板也会重新计算间隔。周末和节假日不计，缺少必要的历史收盘天梯时停止本次收录，不能把缺失当作未涨停。

选中自动收录的股票行后，可点「停止记录」或「恢复记录」，右键菜单也提供此操作。停止对同一代码的全部记录生效，历史保留；同一轮后续3板、4板等继续跳过。停止后新一轮再次达到2板时自动恢复，也可随时手动恢复；是否另起一行仍按10个未涨停交易日判断。恢复后从用户发起的收录继续，不补写停止期间的日期。可撤销停止/恢复操作。

自动更新保留手工描述、黄字、加粗和龙头紫色。描述追加在原自动文字后时，仅更新前面的自动数字；完全改写的文字，例如「炸板+5」，优先完整保留。用户仍自行判断龙头、炸板、缩量、放量、高开秒板、不可排。没有股票代码关联的空白手填行不自动按名称猜测股票，也不自动合并。

收录前保存当前编辑，收录期间暂时锁定表格，避免输入与结果互相覆盖。成功结果显示新增、填写、人工文字保护和停止跳过的数量。多页面更新使用版本校验，旧版本不能覆盖新版本。收录成功后可通过「撤销」恢复收录前的表格。
